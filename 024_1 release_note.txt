BUG FIXES
---------------

---------------
IMPORTANT WARNING
---------------
if upgrading from release 17:
physical zero position has changed from (0,0) in release 17 to (2048,2048) in absolute step value from release 019 onward

1) before taking the code update move 3D positioner to zero position pressing <h>
2) upgrade the code to 019
3) upon boot up and when menu is reached, press ENTER key to reset this position to be your new home position with the 019 new offset handling
